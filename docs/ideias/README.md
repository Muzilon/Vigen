# 🧠 Banco de Ideias e Laboratório (Vigen SGI)

Esta pasta é o laboratório estratégico e criativo do produto.

### 🔄 Fluxo de trabalho (a partir de 2026-09-27)

1. **Estratégia e design (Claude + Eric):** pensamos UX, regras de negócio e diferenciais de mercado e registramos os rascunhos aqui.
2. **Aprovação:** o Eric avalia as ideias.
3. **Passagem de bastão:** ideia aprovada vira **tarefa técnica** em `docs/tarefas/` (schema, escopo de UI, regras de validação).
4. **Execução (Antigravity):** implementa a partir da tarefa, seguindo `docs/00-guia-do-projeto.md`, e registra a entrega em
   `docs/06-desenho-modulos.md`.

---
> ⚠️ **ATENÇÃO, AGENTE DE CÓDIGO:**
> Arquivos dentro de `docs/ideias/` são **RASCUNHOS**. Não implemente funcionalidades, schemas ou telas com base nesta pasta sem
> ordem explícita do Eric ou uma tarefa em `docs/tarefas/`. A fonte da verdade para codificação são os arquivos na raiz de `docs/`
> (comece por `docs/00-guia-do-projeto.md`).
